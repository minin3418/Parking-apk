# Двор-Парковка — APK

Готовые сборки Android-приложения [Parking](https://github.com/minin3418/Parking).
Каждая успешная сборка из ветки `main` автоматически публикуется здесь как релиз.

## Скачать последнюю версию

**[dvor-parking.apk](https://github.com/minin3418/Parking-apk/releases/latest/download/dvor-parking.apk)**

Эта ссылка всегда ведёт на самую свежую сборку. Предыдущие версии — во вкладке
[Releases](https://github.com/minin3418/Parking-apk/releases).

## Установка

1. Скачайте APK на телефон и откройте его.
2. Если Android спросит — разрешите установку из этого источника.
3. Новая версия ставится поверх старой.

## ⚠️ Один раз при переходе на версию 1.20

С версии 1.20 приложение выпускается релизной сборкой с новой подписью. Если у вас
стоит версия 1.17 или старше, Android откажется ставить новую поверх
(«Приложение не установлено» / «конфликт пакетов»). Нужно один раз:

1. Удалить старое приложение «Двор: Парковка».
2. Установить новое по ссылке выше.

Схемы дворов, занятые места, второй ряд и опрос хранятся в общей базе и никуда не
пропадут. На телефоне сбросятся только запомненные номер машины и телефон — их
нужно будет ввести заново. Дальнейшие обновления снова ставятся поверх.
